# Правила

## Слои

Ядро (`packages/core/src/`) не знает о надстройке (`src/app/`) и об оболочке
(`src-tauri/`). Границу проверяет `npm run typecheck:shared`.

Мост — одна точка входа: из кода вне `packages/core/src/bridge` импортируют только
`@/bridge`. Реализацию подставляет сборка псевдопутём `@bridge-impl`, который
прописан в трёх файлах: `vite.config.ts`, `tsconfig.json`,
`tsconfig.shared.json`. Пропустить один — получить расхождение между сборкой и
проверкой типов.

Файлы внутри `packages/core/src/bridge` импортирует только `TauriBridge.ts`.

## Комментарии

Две-три строки и только то, что из кода не видно: причина числа, грабли чужого
API, инвариант, который ломается при нарушении. Пересказывать код комментарием
не нужно. Истории и отвергнутых вариантов в комментариях нет.

## Документация

Документ описывает то, что есть. Того, что было, и того, от чего отказались, в
нём нет.

Стиль единый: русский, формальный, без канцелярита; без «мы» и без обращения к
читателю на «вы»; таблицы там, где перечисление; без эмодзи.

Сухо и коротко. Вещь называют своим именем: «Поиск», «Плеер», «Датасет».
Уточнений, оговорок и пояснений «зачем» не пишут: «Поиск по-русски»,
«свой плеер без чужой рекламы», «чужого кадра нет, а вместе с ним и чужой
рекламы» — лишнее. Не пересказывают сказанное другими словами и не
противопоставляют своё чужому.

Состав `docs/`: `README.md` (вход), `ARCHITECTURE.md`, `INTERFACE.md`,
`DATA.md`, `VIDEO.md`, `STORAGE.md`, `BUILD.md`, этот файл. Новая тема, не
влезающая ни в один файл, — новый файл и строка в `README.md`.

## Проверки

```bash
npm run typecheck:all   # ядро отдельно, затем всё вместе
npm test                # vitest по чистым модулям ядра
npm run build:app       # сборка интерфейса
```

Пройденная проверка типов не значит, что приложение работает: она не видит ни
окна, ни устройства.

Тесты — `tests/`, только чистые модули ядра, vitest.

## Форматирование

Длина строки — 100 знаков.

## Файлы

Файл, который трудно читать целиком, — повод разделить. Запись большого файла
может оборваться посередине и молча; после такой правки файл перечитывают и
сверяют хвост. Обрезанный файл лечится полной перезаписью.

## Данные

`null` означает и «данных нет», и «ответ не доехал» — различение описано в
`DATA.md`. Отбор 18+ идёт только через `core/adult.ts`, а не чтением ключа
настроек на месте.

## Git

Коммит и пуш — только по прямой просьбе foulnike. Веток и истории не касаться
самостоятельно.
