# Документация AniMori для приставки

Клиент AniList со своим интерфейсом под Android TV. Оболочка — Tauri 2 (Rust),
интерфейс — Vue 3, общее ядро — TypeScript без DOM.

| Файл | О чём |
| --- | --- |
| `ARCHITECTURE.md` | слои, ядро, мост, экраны, оболочка на Rust |
| `INTERFACE.md` | пульт, фокус, рельс, темы, плавность на слабом устройстве |
| `DATA.md` | источники данных, датасет названий, сеть, темп, прокси |
| `VIDEO.md` | плеер, источники видео, память просмотра |
| `STORAGE.md` | что и где лежит: настройки, снимок, склад, облако, выгрузка |
| `BUILD.md` | сборка APK, подпись, грабли инструментов |
| `CONVENTIONS.md` | правила кода и документации |

Репозиторий — `foulnike/Animori-TV`, ветка `main`. Десктопная сборка
(`foulnike/Animori-Desktop`) и юзерскрипт (`foulnike/Animori-Script`)
живут отдельно: общего кода и общих файлов с ними нет.

Описание продукта и порядок установки — в `README.md` в корне репозитория.

## Команды

```bash
npm run dev:app         # интерфейс в браузере, без оболочки
npm run build:app       # проверка типов и сборка интерфейса в dist/app
npm run typecheck:all   # ядро отдельно, затем всё вместе
npm test                # vitest, проверки чистых модулей ядра
npm run tauri:build     # сборка оболочки под текущую платформу
```

`tauri:dev` пересобирает интерфейс целиком: горячей подстановки нет.
