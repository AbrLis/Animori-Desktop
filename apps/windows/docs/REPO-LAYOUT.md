# Устройство репозитория

## Ветка

Одна: `main`. Веток на разработку нет.

## Каталоги

| Каталог | Что в нём |
| :--- | :--- |
| `packages/core/src` | Общее ядро: `api`, `core`, `bridge`, `utils` |
| `packages/core/tests` | Наборы общего ядра и заглушка моста |
| `apps/windows` | Настольное приложение |
| `apps/android-tv` | Приложение для телевизора |
| `.github/workflows` | Сторож датасета, проверки, оба выпуска |

## Сборка и проверки

```bash
npm ci                                      # корень
npm test                                    # ядро, потом оба приложения
npm run typecheck                           # оба приложения
npm run build:windows
npm run build:android-tv
```

Разработка идёт из каталога приложения:

```bash
cd apps/windows && npm run tauri dev
cd apps/android-tv && npm run tauri -- android dev
```

## Граница ядра

`typecheck:shared` у каждого приложения собирает ядро в проекте, где надстройки
не существует. Стрелка из ядра в экран или оболочку роняет сборку.

## Выпуски

| Продукт | Тег | Что собирается |
| :--- | :--- | :--- |
| Настольное | `windows-v<версия>` | NSIS, MSI, портативный архив |
| Телевизор | `android-tv-v<версия>` | `armv7` и `arm64` |

Номер в теге сверяется с `package.json` приложения; расхождение роняет прогон.

Канал обновлений Windows — релиз `windows-latest`. Он помечен предварительным:
иначе занимал бы метку «последний выпуск» и ломал ручные ссылки на установщик.
Конвейер создаёт его заново на каждом выпуске и проверяет адрес, который читает
апдейтер.

Файлы приставки называются `AniMori_<версия>_<разрядность>.apk`; разрядность
приложение выбирает по своёй.

## Грабли

Папки сборки в `src-tauri/target` переживают перемещение каталогов и хранят
старые абсолютные пути. После переезда cargo не перезапускает скрипт и падает на
чтении файла, которого нет. Лечится удалением `src-tauri/target/debug/build`:

```powershell
Get-ChildItem apps/windows/src-tauri/target/debug/build -Directory |
  Remove-Item -Recurse -Force
```

Полная чистка `src-tauri/target` помогает тоже, но это пересборка всех
зависимостей заново.
